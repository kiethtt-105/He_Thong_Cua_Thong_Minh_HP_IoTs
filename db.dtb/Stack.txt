===============================================================  

Backend: Django + Django REST Framework — expose API cho web/app

===============================================================

DB: Supabase như schema đã thiết kế 
    Dùng inspectdb để tạo model từ schema có sẵn (vì DB được quản lý bằng raw SQL/trigger, không nên để Django tự migrate đè lên)

===============================================================

Kết nối thiết bị IoT (khoá cửa, đầu đọc NFC): MQTT (paho-mqtt hoặc mosquitto broker) 
    Thiết bị publish trạng thái, backend subscribe và ghi vào device_status_logs/device_commands

===============================================================

Realtime push (remote_auth_requests, notifications): Django Channels (WebSocket) || Firebase Cloud Messaging (push tới điện thoại khi app không mở)

===============================================================

Task định kỳ (dọn OTP/pending_registrations hết hạn): Celery + Redis

===============================================================

App di động (quét NFC, nhận push xác nhận): Flutter || React Native cả hai đều Support NFC read.
