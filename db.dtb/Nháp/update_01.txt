II. CAC HANG MUC CAN SUA NGAY
============================================================

1. FERNET KEY DANG HARD-CODE
------------------------------------------------------------

HIEN TAI:
- File dang co FERNET_KEY gan truc tiep trong models.py.
- Ben duoi lai co logic doc FERNET_KEY tu environment.

CAN SUA:
- Xoa key hard-code khoi source code.
- Chi doc key tu bien moi truong / .env.
- Chi khoi tao Fernet tu environment variable.
- Neu key da tung duoc commit/public tren Git thi nen tao key moi.

MUC DO:
RED - BAO MAT


2. USER NEN DUNG DJANGO AUTH
------------------------------------------------------------

HIEN TAI:
- User dang ke thua models.Model.
- Tu luu password_hash.
- Tu quan ly is_staff, is_superuser, is_active.
- Co ham set_password/check_password rieng.

CAN SUA:
- Can nhac chuyen User sang AbstractBaseUser + PermissionsMixin.
- Su dung co che authentication chuan cua Django.
- Giu lai cac field rieng cua Smart Lock:
  email
  full_name
  phone
  avatar_url
  email_verified
  cac cau hinh 2FA
- Tranh tu xay lai authentication core cua Django.

MUC DO:
RED - CAU TRUC


3. IS_OWNER + SIGNAL MAINTAIN_IS_OWNER
------------------------------------------------------------

HIEN TAI:
- User co is_owner.
- Device co owner.
- Cuoi file co signal maintain_is_owner().
- Logic hien tai co nguy co khong reset owner cu khi owner thay doi.
- Truong hop owner bi xoa/null cung can xu ly ro rang.

CAN SUA:
- Uu tien bo User.is_owner neu no chi dung de bieu dien owner cua Device.
- Xac dinh owner bang Device.owner_id.
- Neu van giu is_owner thi phai thiet ke lai co che dong bo owner cu / owner moi.

MUC DO:
RED - TINH NHAT QUAN DU LIEU


4. PERMISSIONS DANG BI TRUNG GIUA JSONFIELD VA MODEL PERMISSION
------------------------------------------------------------

HIEN TAI:
- Permission la model rieng.
- DeviceAccess lai luu permissions bang JSONField.

CAN SUA:
- Can nhac thay DeviceAccess.permissions = JSONField bang ManyToManyField(Permission).
- Permission model tro thanh nguon du lieu quyen duy nhat.
- De query, cap/quyen, revoke va quan ly permission de dang hon.

MUC DO:
RED - THIET KE CSDL


5. VALIDATOR BATTERY_LEVEL
------------------------------------------------------------

HIEN TAI:
- Device va DeviceStatusLog dung validator lambda de gioi han 0-100.

CAN SUA:
- Dung MinValueValidator(0).
- Dung MaxValueValidator(100).
- Tranh lambda trong model field cho schema lau dai.

MUC DO:
ORANGE - KY THUAT

XIV. CAC DIEM CAN Dac BIET KIEM TRA TRUOC KHI MIGRATE
============================================================

1. Khong sua models roi migrate ngay tren database production.
2. Backup database truoc khi migration.
3. Kiem tra du lieu cu truoc khi doi ForeignKey/ManyToMany.
4. Neu doi User sang AbstractBaseUser, phai lap ke hoach migration rieng.
5. Neu bo is_owner, kiem tra tat ca code dang tham chieu field nay.
6. Neu doi permissions tu JSON sang ManyToMany, phai migrate du lieu cu.
7. Neu rotate FERNET_KEY, phai co ke hoach decrypt/re-encrypt cac secret cu.
8. Kiem tra cac API/serializer/admin/view dang dung cac field cu.
9. Kiem tra signal sau khi sua model.
10. Chay test truoc va sau migration.
