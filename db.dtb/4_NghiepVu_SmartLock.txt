CÁC NGHIỆP VỤ CỦA SMARTLOCK (User scenarios)
================================================================================

1. ĐĂNG KÝ TÀI KHOẢN
   - Tạo PendingRegistration (OTP email)
   - Verify OTP → tạo User + EmailOtpChallenge

2. ĐĂNG NHẬP
   - Tạo Session + RemoteAuthRequest (push-auth)
   - 2FA: Email OTP / TOTP / HOTP / Backup Code / FIDO2

3. CLAIM THIẾT BỊ
   - Verify device_code + provisioning_secret_hash
   - Tạo DeviceAccess + set owner + status = 'online'

4. CHIA SẺ KHÓA
   - Tạo DeviceAccess (permissions: device.manage_cards…)
   - Gửi share_code_hash → user accept

5. QUẢN LÝ THẺ NFC
   - Register AccessCard (card_uid_hash)
   - CardDeviceAccess (thêm/ xóa thẻ cho device)

6. HỖ TRỢ ADMIN
   - Owner tạo SupportRequest (action=RESET/RECOVERY)
   - Admin approve + execute (recovery_code)

7. NHẬT KÝ & THÔNG BÁO
   - AuditLog (append-only)
   - Notification (UNLOCK_SUCCESS, TAMPER, LOW_BATTERY…)

8. RATE LIMIT & BRUTE-FORCE
   - LoginOtpAttempt + cron dọn cũ
   - OTP max retry = 5

9. CẤU HÌNH HỆ THỐNG
   - SystemSettings (singleton)
   - Announcement (có level: info/warning/danger)
================================================================================
